## 기능 요구 사항 
- 3자리의 수를 맞추는 게임 
- 사용자가 3개의 수를 입력
  -[x]  사용자의 입력을 받는다 
- 컴퓨터는 랜덤 3자리 수를 생성 : `camp.nextstep.edu.missionutils.Randoms`의 `pickNumberInRange()`를 활용
  -[x] 랜덤숫자를 생성한다  
- 입력에 대한 결과를 출력 
  - 같은 수가 같은 자리에 있으면 `스트라이크`
  - 같은 수가 다른 자리에 있으면 `볼`
  - 같은 수가 전혀 없으면 `낫싱`
    -[ ] 사용자가 입력한 값을 검사한다 
    -[ ] 사용자가 입력한 값을 대조하여 스트라이크,볼,낫싱 을 판정한다 
    -[ ] 3스트라이크 일시 게임을 종료한다 : 3스트라이크를 먼저 말한뒤 종료멘트 
    -[ ] 대조하여 판정된 값으로 결과 문자열을 생성한다 
    -[ ] 생성한 문자열을 출력한다 
- 같은 과정을 반복 
- 3개의 숫자를 모두 맞히면 게임 종료 
  - 게임을 다시 시작 : 1 
  - 게임을 완전히 종료 : 2
    - [ ] 게임이 종료되면 사용자의 계속여부의사를 입력받는다 
    - [ ] 계속여부의사를 입력한다 
    - [ ] 입력받은 계속여부의사에 따라 게임을 새로시작 or 종료 한다 

## 출력 멘트 
- 게임 시작 멘트 
"숫자 야구 게임을 시작합니다."
- 숫자 입력 멘트 
"숫자를 입력해주세요 : "
- 결과 출력 멘트
"1볼 1스트라이크"
- 결과 출력 멘트(if 3strike)
"3개의 숫자를 모두 맞히셨습니다! 게임 종료"
- 게임 계속 의사 멘트 
"게임을 새로 시작하려면 1, 종료하려면 2를 입력하세요."
