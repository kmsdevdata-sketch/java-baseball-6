### 기능 요구 사항 작성 
기능 요구 사항을 작성하였다 작성한 방식은 
요구사항 명세를 확인하며 요구사항을 기능별로 분리 -> 기능별로 분리된 요구사항에 맞춰 필요한 작업을 분리 -> 정확히 어떠한 요구사항에 맞는 기능인지 보정 
####아쉬운점
- 기능요구사항을 분리할때 카테고리에 맞는 분류를 하면 더욱 한눈에 보기 편할듯함 (ex.출력,입력,기능 등등) 하지만 어떠한 보편적인 기준을 갖고 분리할지머릿속에 확립되지 않아 우선은 보았을때 불편하지 않을정도로만 분리하였음 
- 정확한 절차를 머릿속에서 떠올리기 어려움(정말 필요한 기능이 모두 작성되었는지 정확히 판별이 되지않음)
- 해당 기능에 필요한 테스트는 떠올려지지 않음
